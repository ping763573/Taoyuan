漫遊桃園・探索桃園區 — 使用說明

【最簡單的開啟方式】
1. 解壓縮 taoyuan_website.zip，會得到一個資料夾 taoyuan_website
2. 進入資料夾，雙擊 index.html
3. 就會在瀏覽器（Chrome / Edge / Safari）開啟，不需要安裝、不需要網路伺服器

【為什麼之前打不開】
之前給的是平台預覽檔，解壓後沒有 index.html，所以瀏覽器不知道要開哪一頁。
這次的包已修正：根目錄就是 index.html，圖片都在 images/ 資料夾裡。

【資料夾結構】
taoyuan_website/
  index.html        ← 主程式，雙擊這個
  images/          ← 12 張桃園區實景照片，不要刪除或改名
    shrine.jpg / hutoushan.jpg / jingfu.jpg / kongmiao.jpg
    q77.jpg / yiwen.jpg / huanbao.jpg / fenghe.jpg
    oyster.jpg / guotie.jpg / mifen.jpg / nightmarket.jpg
  README.txt       ← 本說明

【注意事項】
- 請保持 index.html 和 images/ 在同一個資料夾，不要只單獨複製 index.html 出來，否則照片會破圖。
- 建議用 Chrome 或 Edge 開啟，手機版會自動變漢堡選單。
- 本網站為教育推廣、非官方網站。人口數字皆標示統計年月與來源。
