漫遊桃園・探索桃園區 - 使用說明

【這包解開後你會看到】
- index.html：就是整個網站，已經包含忠烈祠照片修正版
- README.txt：就是這個檔案

【怎麼打開】
方法一：直接雙擊 index.html，用 Chrome 或 Edge 開
方法二：如果雙擊是白畫面：
  Windows：在這個資料夾網址列輸入 cmd，按 Enter，輸入 python -m http.server 8000
  Mac：終端機 cd 到這個資料夾，輸入 python3 -m http.server 8000
  然後瀏覽器開 http://localhost:8000，再點 index.html

【注意】
- 要連網路，地圖才載得出來
- 不要在壓縮檔裡面直接雙擊，要先按右鍵「解壓縮全部」完整解出來
- Windows 預設會隱藏副檔名，index 可能只顯示 index + Chrome 圖示，那個就是 index.html
